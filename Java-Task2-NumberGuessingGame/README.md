# Number Guessing Game (Java)

A console-based game where the computer picks a random number and the player guesses it with Too High / Too Low hints.

## Features
- Random number generated every round
- Hints: "Too High!", "Too Low!", "Correct!"
- Attempt counter and maximum attempts limit
- "You Lost!" message that reveals the number
- Play Again option and score tracking across rounds
- Difficulty levels: Easy (1-50, 10 attempts), Medium (1-100, 7 attempts), Hard (1-200, 5 attempts)
- Input validation for non-numeric and out-of-range guesses

## How to Run
javac NumberGuessingGame.java
java NumberGuessingGame

## Concepts Used
java.util.Random, Scanner, loops, conditionals, methods
